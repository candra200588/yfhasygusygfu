# EXP Lane Academy – Website

Situs statis (HTML + CSS) untuk usaha edukasi EXP lane Mobile Legends.

## Halaman
- index.html – cover dengan gambar hero EXP lane
- materi.html – pilihan materi
- laning-phase.html, pilihan-hero.html, counter-hero.html, oper-war.html – isi materi

## Cara pakai
1. Taruh gambar hero di assets/img/ dengan nama hero-1.jpg, hero-2.jpg, hero-3.jpg (lihat BACA-SAYA.txt).
2. Ganti nama usaha, kontak WhatsApp (index.html: 62XXXXXXXXXX), dan isi materi.
3. Upload ke GitHub, lalu aktifkan GitHub Pages (lihat PANDUAN-GITHUB-GOOGLE-SITES.md).

Jika gambar belum ada, panel hero tampil sebagai blok warna sehingga situs tetap rapi.
